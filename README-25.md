# Hunter Forkop для OpenWrt 25.12 / ARM64

Предварительный выпуск **0.1.0-rc1**. Официальный Forkop 1.0.5 (APK), закреплённый sing-box-extended 1.14.1-extended-2.7.2 compressed и патч импорта XHTTP. Это установщик компонентов, не прошивка роутера.

## Установка

Поддерживается только **OpenWrt 25.12.x, aarch64/ARM64, APK**. На чистой системе требуется 80 MB свободной flash; при существующем Forkop — 35 MB. Доступная RAM — минимум 130 MB. Нужны рабочий WAN, правильное время и доступ к официальным репозиториям точной версии прошивки. Несовместимые VPN-пакеты и неизвестные версии Forkop отклоняются.

```sh
wget -O /tmp/hunter-forkop25.sh https://raw.githubusercontent.com/gerser777/Hunter-Forkop/hunter-forkop-25-v0.1.0-rc1/install-25.sh && sh /tmp/hunter-forkop25.sh
```

Проверка без изменения настроек:

```sh
sh /tmp/hunter-forkop25.sh --check
```

Сначала скачиваются компоненты и проверяются SHA256. Затем создаётся `/root/hunter-backups/installer-<UTC>-<PID>/`: настройки, старый движок, список пакетов и команда отката. На существующей работающей конфигурации VPN кратковременно перезапускается, проверяются HTTPS через main-out и DNS. Эта версия проверки рассчитана на секцию `main`; для другой структуры сначала требуется адаптация.

Внешние APK Forkop сверяются с опубликованными SHA256, затем устанавливаются с `--allow-untrusted`; ключи доверия системы не меняются. Официальный sing-box устанавливается отдельно штатным APK. Не обходятся проверки зависимостей или версии ядра. Используемый парсер закреплён на неизменяемом теге предыдущего выпуска с тем же проверенным содержимым.

На чистой системе установщик не добавляет подписку и не запускает VPN. Откройте LuCI → Forkop, добавьте свою подписку, настройте правила и Auto. В поставке нет UUID, ключей, адресов личной панели или клиентских подписок.

## Auto

В секции `main` создайте группу приоритетов «Auto recomend». Для схемы Hunter: прямые XHTTP/gRPC — уровень 1, LTE — уровень 2. Фильтры имён: `[123]` с исключениями `Forkop`, `LTE`; резерв — `LTE`. Эти фильтры подходят только подпискам с соответствующими именами.

Выбирать самый быстрый при выборе уровня; активная проверка 10s, timeout 3s, возврат 30s. Переключение ради меньшей задержки внутри рабочего уровня выключено, принудительное прерывание соединений выключено. Выберите Auto в списке подключений; обычные подключения сохраняются. Сам установщик не создаёт группу и не добавляет доступ к LTE.

DNS и списки маршрутизации задаются отдельно. Установщик сохраняет существующие настройки и не включает AdGuard автоматически. Кнопка Auto в панели Hunter управляет Happ; выбор группы на роутере локальный.

## Откат

Установщик печатает точную команду:

```sh
sh /root/hunter-backups/installer-<UTC>-<PID>/rollback.sh
```

Откат возвращает настройки/движок и запускает ранее работавшую службу; удаляет новые основные пакеты. Общие зависимости могут остаться. Копируйте резервную папку на компьютер. При ошибке установки выполняется откат; на этапе переключения движка есть таймер 15 минут. Откат не восстанавливает прошивку целиком и не заменяет резервную копию роутера.

APK продолжает учитывать штатную версию sing-box, реальный движок отмечен как extended-compressed. Обновление sing-box/Forkop может заменить движок/патч — после обновления нужны повторные проверки.

## Проверки

Cudy WBR3000UAX v1 (OpenWrt U-Boot layout), OpenWrt 25.12.5, kernel 6.12.94: установка APK на чистую систему, все восемь кандидатов Auto, переход direct → LTE → direct, отказ всех путей, DNS, автозапуск после программной перезагрузки и HTTPS через 14 ручных профилей + Auto. Владелец подтвердил сайты и YouTube через LAN. Эти проверки конфигурации выполнены до упаковки установщика.

Установщик: ash syntax, проверка платформы, отклонение OpenWrt24/другой архитектуры/версии/конфликтов, изолированное восстановление файлов. Полный запуск готового установщика поверх работающего Forkop на Cudy25 завершился exit=0: резервная копия создана, служба восстановлена, встроенные HTTPS/DNS проверки успешны, 14 ручных профилей и выбранный Auto сохранены. Чистая установка именно готовой командой, физическое выключение питания, длительная нагрузка и другие модели отдельно не проверялись. Поэтому выпуск предварительный.
