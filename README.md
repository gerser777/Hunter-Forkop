# Hunter Forkop для OpenWrt 24.10 / ARM64

Версия **0.1.0-rc2**, предварительный установщик поверх Forkop 1.0.5. Это не прошивка роутера и не заново скомпилированный Forkop. Используются официальные IPK Forkop/LuCI и закреплённая сборка sing-box-extended; добавляется наш открытый патч импорта XHTTP.

## Установка

Только OpenWrt **24.10.x**, архитектура **aarch64/ARM64**, не менее 35 MB свободной flash и 130 MB доступной RAM. Системы с конфликтующими VPN-пакетами и неизвестной версией Forkop отклоняются. OpenWrt 25, MIPS, ARMv7 и x86 этой версией не поддерживаются.

В SSH от root:

```sh
wget -O /tmp/hunter-forkop.sh https://raw.githubusercontent.com/gerser777/Hunter-Forkop/hunter-forkop-24-v0.1.0-rc2/install.sh && sh /tmp/hunter-forkop.sh
```

Только проверка без изменений:

```sh
sh /tmp/hunter-forkop.sh --check
```

Зависимости устанавливаются из настроенных официальных opkg feeds. Репозитории должны соответствовать точной версии ядра прошивки; проверки зависимостей не обходятся. Дополнительно устанавливается coreutils-timeout, если отсутствует.

Установщик заранее скачивает и сверяет SHA256 компонентов, сохраняет старый движок и конфигурации в `/root/hunter-backups/installer-<UTC>-<PID>/`. Затем устанавливает нужные пакеты, проверяет движок, сохраняет существующие настройки. Для уже работающего Forkop проверяет HTTPS через выбранный outbound и локальный DNS. При ошибке возвращает копию; на этапе переключения движка действует watchdog 15 минут.

На чистой системе VPN не запускается: откройте LuCI → Forkop и добавьте **свою** подписку. Чужих UUID, подписок, SSH-ключей и настроек домашнего роутера в поставке нет. Если LuCI отсутствует в прошивке, сначала установите штатный LuCI.

## Auto

После добавления подписки в секции Forkop создайте группу приоритетов «Auto recomend»:

- первый уровень: прямые XHTTP/gRPC, фильтр имён `[123]`, исключения `Forkop` и `LTE`;
- второй уровень: фильтр имён `LTE`;
- выбирать самый быстрый при выборе уровня; проверка 10s, timeout 3s, возврат 30s;
- переключение ради меньшего пинга внутри рабочего уровня выключено;
- выберите эту группу в списке подключений. Обычные подключения сохраняются.

Группа требует LTE-профилей в вашей учётке. Если их нет, добавьте через основную панель. Переключатель «Auto клиентов» в 3x-ui управляет выдачей Auto для **Happ**, а выбор группы на роутере остаётся локальным.

## Откат и обновления

Установщик печатает точную команду:

```sh
sh /root/hunter-backups/installer-<UTC>-<PID>/rollback.sh
```

Откат возвращает движок и настройки, удаляет новые основные пакеты, которых не было до установки. Новые общие зависимости могут остаться установленными. Полный снимок всей файловой системы не создаётся. Скопируйте резервную папку с роутера на свой компьютер.

Фактический движок фиксируется маркерами Forkop `extended-compressed`; запись пакета opkg sing-box остаётся штатной. Обновление штатного sing-box может заменить наш движок, обновление Forkop — патч. После обновлений снова проверяйте XHTTP и LTE. Патч рассчитан именно на Forkop 1.0.5.

## Что проверено

На Cudy WBR3000UAX v1, OpenWrt 24.10.5: эти движок и патч уже работают, восемь прямых/LTE путей передают HTTPS, владелец подтвердил LAN. Сам установщик прошёл ash syntax, read-only preflight на Cudy, изолированные тесты запрета OpenWrt 25/другой архитектуры/версии/конфликтов и восстановления старых файлов. **Чистая установка этим установщиком и перезагрузка после неё ожидают проверки.** Поэтому выпуск предварительный. Работающий Cudy повторно не переустанавливался.
